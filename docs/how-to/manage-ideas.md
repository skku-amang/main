# 아이디어 관리하기

> **For**: 기능·개선 아이디어를 제안·검토·착수하는 팀원(기획·디자인·개발 누구나).
> **You'll be able to**: 아이디어를 어디에 올리고, 어떻게 우선순위를 매기고, 언제 GitHub 작업으로 넘기는지 안다.

이 구조를 **왜** 이렇게 정했는지는 [ADR-0004](../explanation/adr/0004-idea-pipeline-ssot.md) 참조. 여기서는 **어떻게 하는지**만 다룬다.

아이디어 보드: **[Notion Task DB](https://www.notion.so/2dfbbc180bd6802b8fe2d4ee6d2c744d)**

---

## 전체 흐름

```
[Notion Task DB]                              [GitHub]
검토 전 ──(회의 검토·채점)──▶ 진행 중 ─────────▶ Milestone 생성
                              │                   └─ Issue = 세부 태스크
                           완료 / 취소             PR로 구현
```

아이디어·우선순위는 Notion, 실제 구현은 GitHub. 같은 내용을 양쪽에 중복 저장하지 않는다.

---

## 1. 아이디어 올리기

Notion Task DB에 새 항목을 `검토 전` 상태로 추가한다.

- **이름**: 아이디어 한 줄
- **영역**: 기획 / 백엔드 / 프론트 / 인프라 / AX / 디자인 중 하나
- **메모**: 배경·맥락 (있으면 출처도)

누구나 자유롭게 올릴 수 있다. 이 단계에선 다듬어지지 않은 날것도 괜찮다.

## 2. 회의에서 검토·채점

회의에서 아이디어를 함께 보고 네 축을 **1~5**로 매긴다.

| 축 | 뜻 |
| --- | --- |
| 구현 난이도 | 만들기 얼마나 어려운가 (낮을수록 좋음) |
| 사용자 효용 | 동아리원(부원)에게 얼마나 이로운가 |
| 운영진 효용 | 운영진에게 얼마나 이로운가 |
| 확신도 | 위 효용 추정을 얼마나 믿을 만한가 |

**우선순위 점수**가 자동으로 계산된다(소수 1자리):

```
avg(사용자 효용, 운영진 효용, 6 − 구현 난이도) × (확신도 / 5)
```

- 값 범위 1~5. 점수 내림차순 정렬 = 백로그 우선순위.
- 근거가 약하면(확신도 낮음) 점수가 눌린다 — "느낌만 좋은" 아이디어가 위로 못 올라오게.

> 확실히 안 할 것만 `취소`로. "지금은 아니지만 언젠가"는 `검토 전`에 남겨둔다.

## 3. 착수 — GitHub로 넘기기

하기로 한 아이디어를 `진행 중`으로 바꾸고, GitHub에 작업 공간을 만든다.

1. GitHub에 **Milestone**을 만든다. 제목 = 아이디어 이름.
2. Notion 아이디어의 **메모(또는 별도 필드)에 그 Milestone URL을 링크**한다 — 양쪽을 클릭 한 번에 오갈 수 있게.
3. Milestone 안에 세부 작업을 **이슈**로 쪼갠다. 커밋·PR은 이슈에 연결한다.

| Notion | GitHub | 관계 |
| --- | --- | --- |
| 아이디어 (진행 중) | Milestone | 1 : 1 |
| — 세부 태스크 | Milestone 안 Issue | 1 : N |

> 큰 아이디어(에픽)도 Milestone 하나에 이슈를 평면으로 나열한다. Notion의 `상위/하위 항목`으로 에픽↔하위 아이디어를 묶어도 된다.

## 4. 완료 처리

Milestone의 이슈가 모두 닫히면(완료율 100%) Notion 아이디어를 `완료`로 옮긴다.

Notion 상태와 GitHub 진행은 자동 동기화하지 않는다 — 착수할 때(`진행 중`)와 끝났을 때(`완료`)만 손으로 맞춘다.

## Notion Task DB 필드 요약

| 필드 | 타입 | 용도 |
| --- | --- | --- |
| 이름 | title | 아이디어 한 줄 |
| 상태 | status | 검토 전 / 진행 중 / 완료 / 취소 |
| 영역 | select | 기획 / 백엔드 / 프론트 / 인프라 / AX / 디자인 |
| 구현 난이도 · 사용자 효용 · 운영진 효용 · 확신도 | number | 채점 1~5 |
| 우선순위 점수 | formula | 자동 계산 |
| 메모 | text | 맥락·출처·GitHub Milestone 링크 |
| 상위/하위 항목 | relation | 에픽 ↔ 하위 아이디어 |
