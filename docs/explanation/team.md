# AMANG 팀 영역 분담

본 파일은 AMANG 운영 팀의 영역별 책임 **SSOT**. 학기마다 변경 가능 — 변경 시 본 파일 먼저 업데이트하고 회의에서 확정.

---

## 26-1 학기 (2026 봄)

| 팀원 | 영역 | 주요 작업 |
|---|---|---|
| **윤규성** | 기획 | 기능명세서, 와이어프레임 |
| **수연 김** | 디자인 | UI 디자인 |
| **남승민** | 백엔드 | ERD 작성, API 구현 |
| **손장수** | 인프라 + 프론트 + AX | K8s/ArgoCD 운영, 웹 퍼블리싱, AX(AI Experience) |

---

## 영역별 상세

### 기획 (yungs)
- 사용자 시나리오 정의, 기능명세서 작성, 와이어프레임 (Figma)
- 운영 정책 결정 (강제도, 알림 빈도 등)
- 디자인·백엔드의 input

### 디자인 (수연 김)
- UI 디자인 (Figma)
- 인터랙션·시각 일관성
- 디자인 시스템 SSOT

### 백엔드 (남승민)
- Prisma schema·ERD
- NestJS API 구현
- 데이터 모델 결정 (정규화·polymorphism·index 전략)

### 인프라 + 프론트 + AX (손장수)
- K8s 클러스터, ArgoCD GitOps, MinIO·DB·인증 등 인프라
- Next.js 웹 구현 (디자인 시안 기반)
- **AX (AI Experience)** — AI 활용 차원. feature별 정의 다름:
  - 피드백 시스템: 이상 피드백 탐지, 코멘트 요약 등
  - 향후: 운영 판단·도메인 융합·딥링크 자동화 등
